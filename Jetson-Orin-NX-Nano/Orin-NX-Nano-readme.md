# NVIDIA Jetson Orin NX and Orin Nano

The NVIDIA Jetson Orin NX and the Orin Nano modules only supports Linux, and a limited number of distributions. The NVIDIA build tool for making an image has been adopted by RTD to work with the CNV36JRN201 boards. This includes additional hardware breakouts required to use the PCIe-104 form factor. RTD provides software that is required to build the Linux image that includes these changes in a GitHub repository [here](https://github.com/RTD-Embedded/CNV36JRN201). Carefully follow the instructions using a native Ubuntu 22.04 LTS host computer to cross-compile the Linux image.

When purchased from RTD, the CNVJRN201 will have the latest version of the NVIDIA Linux image on it and include some basic utilities. Additional software for using the Jetson NX are provided by [NVIDIA](https://developer.nvidia.com/embedded/jetson-linux-r3541).


For any additional software assistance for use with the CNV36JRN201HR please contact RTD technical support.
